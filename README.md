# Чисто Так 🧹

Комерційний вебсайт для української клінінгової компанії **«Чисто Так»**.

## 📌 Про проєкт

Реальний клієнтський проєкт для малого бізнесу.

Мета сайту — презентувати послуги компанії, покращити онлайн-присутність та приймати заявки від потенційних клієнтів.

Проєкт містить frontend частину та невеликий PHP backend для обробки форми замовлення і надсилання заявок у Telegram.

## ✨ Реалізовано

- Адаптивна верстка для ПК, планшетів та смартфонів
- Сучасний UI/UX дизайн
- Блоки послуг компанії
- Форма замовлення прибирання
- Інтеграція з Telegram Bot API
- Базова SEO оптимізація
- Оптимізована HTML-структура

## 🛠 Технології

- HTML5
- CSS3
- JavaScript
- PHP
- Telegram Bot API

## 🚀 Локальний запуск

Необхідно:

- PHP 8.1+
- Telegram Bot (для тестування заявок)

Запуск:

```bash
php -S localhost:8000 -t .
```

Відкрити:

```text
http://localhost:8000/
```

## 🔐 Безпека

Секретні дані не зберігаються у репозиторії.

Використовуйте `.env` на основі `.env.example`:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_ADMIN_CHAT_ID=
APP_TIMEZONE=Europe/Kyiv
```

Не додавайте у Git:

- токени ботів
- API ключі
- паролі
- приватні конфігурації сервера
